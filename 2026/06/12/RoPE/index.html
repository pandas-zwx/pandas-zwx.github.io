RoPE的数学原理及代码实现

Posted on 2026-06-12 In 机器学习(搬运自我的简书)

这部分的内容是在 2025年 11 月发布在简书上的，现在搬运到我的 blog 上面。

1 起源

由于经典的位置编码，也就是正弦余弦位置编码，主要是给每个 token 加上一个绝对位置表示。它告诉模型“这个 token 在第几个位置”，但是没有直接把“两个 token 相隔多远”写进 attention 计算中。因此，模型需要从数据中间接学习相邻词、远距离词等相对位置关系。RoPE 的改进点在于，它不是简单地把位置编码加到 token embedding 上，而是在计算 attention 的时候，对 query 和 key 做旋转变换。这样一来，attention score 中会自然带有两个 token 之间的相对位置信息。也就是说，模型在判断两个 token 是否相关时，不只看它们的语义，也会更直接地感知它们之间的距离。
